A structured collection of code examples, study notes, and practice exercises designed for learning and mastering the **C programming language** from the ground up.

---

## 📖 About The Repository

This repository serves as a comprehensive guide and personal reference for C programming concepts. Whether you are a computer engineering student or a self-taught developer, you will find clean, well-commented code examples covering fundamental syntax, memory management, and foundational algorithms.

---

## 🗂️ Topics Covered

* **01. Basics & Syntax:** Variables, data types, operators, and standard Input/Output (`printf`, `scanf`).
* **02. Control Flow:** Conditional statements (`if-else`, `switch-case`) and loops (`for`, `while`, `do-while`).
* **03. Functions & Scope:** Function declarations, recursion, parameter passing, and variable scope.
* **04. Arrays & Strings:** 1D/2D arrays, string manipulation, and standard `<string.h>` library functions.
* **05. Pointers & Memory Management:** Pointer arithmetic, dynamic memory allocation (`malloc`, `calloc`, `realloc`, `free`).
* **06. Structures & Unions:** Custom data types (`struct`, `union`, `typedef`, `enum`).
* **07. File I/O:** Reading from and writing to text and binary files (`fopen`, `fread`, `fwrite`, `fprintf`).
* **08. Algorithms & Exercises:** Practice problems, sorting/searching implementations, and mini-projects.
